## Digi Cyber 1.1.0

Cross-platform release of the current Digi Cyber app, including Android APKs signed with the configured release key so future updates can install over this version.

- Android: APKs for `arm64-v8a`, `armeabi-v7a`, `x86_64` and `x86`, plus a universal APK.
- Windows 10/11, macOS (Intel and Apple silicon), and Linux (x64 and ARM64) installers.
- Includes the location-ping fixes and diagnostics introduced in 1.0.2.
